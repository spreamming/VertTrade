# Stage 14 已知限制

打包前请了解以下限制；多数为免费数据源与个人使用场景的合理取舍。

## 数据与时效

- **非 tick / 非 Level-2**：分钟 K、分时、近实时报价均有延迟，仅供盘中观察。
- **无自动收盘同步**：不会在 15:00 后自动跑批；依赖 stale end-date 检测或手动 `refresh_watchlist_cache.py`。
- **节假日与停牌**：K 线 end 容忍 4 个自然日，避免周末误触发频繁拉取。
- **免费源不稳定**：单接口失败时应看到局部错误、stale 缓存或「上次成功数据」，而非整页崩溃。

## 功能范围

- **仅 A 股行业板块**：概念 / 地域板块未纳入 MVP。
- **指数无价格位置**：主要指数仅展示行情，暂无 250/750/1250 位置分数。
- **板块资金流无分单视角**：仅主力净流入汇总；个股详情才有超大/大/中/小切换。
- **排行榜 THS-only**：与 EM 板块资金流数值可能不完全一致。

## 性能

- Dashboard 自选股近实时刷新默认前 20 行，避免 N 路 live quote 压垮免费源。
- 板块 K 线/资金流 60s 内复用缓存；`refresh=true` 可强制拉新。
- 首次打开自选股较多时，Dashboard 加载可能较慢（逐只补 quote/position/moneyflow）。

## 桌面与部署

- **Stage 15 前无正式安装包**：日常开发请用 `scripts/start_local.py`。
- **SQLite 仍在项目目录**：打包 Stage 15 时会迁到应用数据目录。
- **Electron POC（`desktop/`）**：仅供参考，依赖开发环境 `.venv`。

## 非目标（刻意不做）

- 券商登录、下单、条件单、自动交易
- 账户 / 密码 / token 存储
- 商业级行情分发或多人 SaaS

## 验收标准（Stage 14）

在以上限制下，用户应能完成：**Dashboard 看大盘 → 看板块/排行榜 → 点进个股/板块详情 → 自选股复盘**，且数据源波动时核心路径仍可用。

自动化门禁：`pytest backend/tests/`（60 pass）、`npm run typecheck`、`npm run build`。
