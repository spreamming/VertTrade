# Stage 14 回归验收清单

在 Stage 15 正式打包前，按本清单手动走一遍核心路径。可在本地启动：

```bash
.venv/bin/python scripts/start_local.py
```

浏览器打开 `http://127.0.0.1:5173`。

## 1. Dashboard（每日复盘入口）

| 步骤 | 预期 | 通过 |
|------|------|------|
| 打开 Dashboard | 市场概览（主要指数 + 涨跌家数）可见 | ☐ |
| 等待 15 秒 | 市场概览自动刷新，无整页卡死 | ☐ |
| 查看行业板块列表 | 板块卡片有涨跌幅、主力净流入等字段 | ☐ |
| 查看每日复盘排行榜 | 8 组榜单可见；单组失败时其余组仍显示 | ☐ |
| 查看自选股表格 | 价格、价格位置、主力净流入列可见 | ☐ |
| 断网或数据源失败 | 板块/排行榜显示「上次成功数据」提示，不全屏报错 | ☐ |

## 2. 个股详情

| 步骤 | 预期 | 通过 |
|------|------|------|
| 从搜索进入个股 | 报价摘要、日 K、价格位置、资金流可见 | ☐ |
| 切换 分时 / 分钟 K | 图表正常；分钟 K 有数据源与缓存时间标签 | ☐ |
| 切换价格位置窗口 250/750/1250 | 分数与标签随窗口变化 | ☐ |
| 切换主力资金视角 | 汇总与 K 线柱形图同步变化 | ☐ |
| 近实时行情 | 3 秒轮询；显示 provider 时间与本地刷新时间 | ☐ |
| 加入 / 移除自选 | 按钮状态正确，Dashboard 同步 | ☐ |

## 3. 板块详情

| 步骤 | 预期 | 通过 |
|------|------|------|
| 从 Dashboard 板块进入 | 成分股列表可见 | ☐ |
| 查看板块 K 线与资金流 | 日 K + 主力净流入柱形图可见 | ☐ |
| 数据源失败（若可模拟） | 显示「上次成功缓存」提示而非空白 | ☐ |
| 点击成分股 | 跳转到对应个股详情 | ☐ |

## 4. 排行榜点击穿透

| 步骤 | 预期 | 通过 |
|------|------|------|
| 点击股票榜条目 | 打开个股详情 | ☐ |
| 点击板块榜条目 | 打开板块详情 | ☐ |

## 5. 自选股与收盘后刷新

| 步骤 | 预期 | 通过 |
|------|------|------|
| 添加多只股票到自选 | Dashboard 表格与复盘摘要更新 | ☐ |
| 运行 `scripts/refresh_watchlist_cache.py` | 终端输出各代码刷新结果 | ☐ |
| 再次打开个股详情 | 日 K / 资金流为最新缓存 | ☐ |

## 6. 非交易边界（必须全部为「否」）

| 检查项 | 预期 | 通过 |
|--------|------|------|
| 券商登录入口 | 不存在 | ☐ |
| 下单 / 委托功能 | 不存在 | ☐ |
| 账户凭证存储 | 不存在 | ☐ |
| 自动交易 | 不存在 | ☐ |
